## 🚀 Getting Started

Want to run this local simulation of my professional life?

### Prerequisites

-   **Bun**: You need [Bun](https://bun.sh) installed. If you're still using Node, the agents might judge you.

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/jordanhindo.dev.git

# Enter the directory
cd jordanhindo.dev

# Install dependencies (blazingly fast)
bun install
```

### Running the Development Server

Summon the local instance:

```bash
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

-   `src/app`: The Next.js App Router (where the magic happens).

-   `AGENTS.md`: The "Constitution" for the AI agents working on this repo.

## 🧠 The Philosophy: "AI Orchestration"

This project follows a strict **"Architect First, Code Second"** methodology.

1.  **Research & Plan:** I define *what* we are building and *why*.
2.  **Orchestrate:** I feed context and constraints to the agents.
3.  **Review & Refine:** I review the code, fix the subtle bugs, and guide the architecture.
4.  **Ship:** We deploy.

This allows me to focus on **System Design, User Experience, and Business Logic**, while the AI handles the implementation details.
