# Y Combinator (Work at a Startup) Skill

## When to Use
- When applying to YC companies (Wayline, FurtherAI, Orbis).
- When updating the YC Candidate Profile.

## Key Concepts

### The "Hacker" Persona
YC founders want builders. They don't care about credentials; they care about shipping.
- **Narrative:** "I build systems, I ship daily, I solve hard problems."
- **Project:** Focus on **Hatch-Studios** (The "Distributed OS" narrative).

### Profile Fields

**Short Phrase:**
"AI Systems Engineer building deterministic orchestration layers and MCP infrastructure for autonomous agents."

**What are you looking for?**
"I am looking for a role where I can architect the 'Operating System' for AI agents... I want to solve the 'Last Mile' of reliability... I thrive in environments that value 'shipping as truth'."

**Project Description:**
Focus on **Convergence**:
"I built Hatch-Studios... The Engineering Challenge: Convergence. AI models are terrible at adhering to external asset dependencies... The Solution: I architected a Runtime Orchestrator... Ordered File Concatenation... Shared Asset Injection... Asset Proxy Middleware."

## Application Answers

### "Most Challenging Project"
Use the **Hatch-Studios** narrative:
- Pivot from 2D to 3D.
- Orchestration of Multi-File Dependencies.
- Solution: "Shared Document Strategy" + "Ordered Concatenation".

### "Interesting Paper"
Use the **Turtlez / RLM** narrative:
- Paper: "Large Language Models are Self-Recursive" (arXiv:2512.24601).
- Implementation: "I built Turtlez to test this... recursive functional call stack... no orchestration framework."

## Best Practices
- **Format:** Plain text blocks.
- **Tone:** Technical, opinionated, high-agency.
